# 窗口透明度 / 最大化透视桌面

Windows 后台小工具：用 **Alt + 滚轮** 调节当前激活窗口的整体不透明度；并按屏幕监控最大化窗口。某个窗口最大化时，会把**同一块屏幕**上的其他窗口最小化，同时把最大化窗口设为半透明，从而看清桌面壁纸。取消最大化后，其他窗口会恢复到原来的位置和状态。

## 用法

1. 双击 `启动.vbs`，或在本目录执行：

```powershell
python window_opacity.py
```

2. 任务栏右下角会出现托盘图标。
3. 点一下要操作的窗口，按住 **Alt** 滚动滚轮：
   - 向上：更不透明
   - 向下：更透明（最低约 15%，避免窗口完全消失）
4. 把窗口**最大化**：同屏其他窗口被最小化，当前窗口变为约 85% 不透明。
5. **还原**该窗口：先前被最小化的窗口按原位置恢复。
6. 右键托盘图标可开关「最大化透视桌面」，或退出。

调试（保留控制台、写更详细日志）：

```powershell
python window_opacity.py --debug
```

日志默认写到 `%TEMP%\window-opacity.log`。

## 配置

编辑同目录下的 `config.json`：

| 项 | 含义 | 默认 |
| --- | --- | --- |
| `wheel_step` | Alt+滚轮每格改变的不透明度（0–255） | `10` |
| `min_opacity_percent` | 滚轮能调到的最低不透明度 | `15` |
| `maximize_peek_opacity_percent` | 最大化时的不透明度 | `85` |
| `maximize_peek_enabled` | 是否启用最大化透视 | `true` |
| `scan_interval_ms` | 扫描窗口状态的间隔 | `200` |
| `exclude_class_names` | 忽略的窗口类名 | `[]` |
| `exclude_title_keywords` | 标题包含这些字则忽略 | `[]` |

改完配置后请退出再重新启动本工具。

启动时如果已经有窗口处于最大化，工具不会立刻最小化其它窗口；等你之后再次执行最大化（或在托盘中重新勾选「最大化透视桌面」）才会生效。

## 开机启动

以管理员以外的普通权限运行即可：

```powershell
powershell -ExecutionPolicy Bypass -File .\安装开机启动.ps1
```

卸载：

```powershell
powershell -ExecutionPolicy Bypass -File .\卸载开机启动.ps1
```

## 限制

- 需要 **Python 3.8+**，只用标准库，不必 `pip install`。
- 以管理员身份运行的窗口，普通权限下无法改透明度（UIPI）。若要调节这类窗口，请同样以管理员启动本工具。
- 部分全屏游戏、受保护窗口、个别 GPU 合成窗口可能不支持分层透明度。
- 多显示器按屏幕独立处理：左边最大化不会动右边屏幕上的窗口。
